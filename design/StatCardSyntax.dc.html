A stat card, proposed

A single KPI — value, label, comparison — as its own fence, the same way ```chart already works. No table row required for a number that deserves its own shape.

You write
```statcard
[
  { "label": "Revenue (MTD)",
    "value": "€51,200", "delta": "+8.1%" },
  { "label": "Orders", "value": 1205,
    "delta": "+4.3%" },
  { "label": "Conversion", "value": "2.9%",
    "delta": "+1.1%" },
  { "label": "Payments failed", "value": 3,
    "tone": "danger" }
]
```

Only label and value are required. delta colors and arrows itself from its sign; tone overrides that for a card with no delta, like a plain alert count.
